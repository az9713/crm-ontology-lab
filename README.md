# CRM ontology — a Palantir-style learning project

A small CRM (sales reps, accounts, contacts, leads, opportunities, activities) modelled as a Palantir Foundry ontology. It has two layers:

1. **A local schema.** `crm_ontology/build_ontology.py` writes `ontology.json` in the public `OntologyFullMetadata` shape: 6 object types, 9 link types, 8 action types, 1 interface. `check_ontology.py` validates it against the open-source `foundry-platform-sdk` models.
2. **A Foundry build.** The author's own transform code (`foundry/transforms/crm.py`) and function code (`foundry/functions/index.ts`) built the same model on a Foundry Developer Tier (AIP Now) enrollment.

The full explanation, with four diagrams, is in `docs/CRM-Ontology-Guide.html`. Read it live at **https://az9713.github.io/crm-ontology-lab/CRM-Ontology-Guide.html**.

## Run the local part

    cd crm_ontology
    python build_ontology.py       # writes ontology.json and runs structural checks
    pip install foundry-platform-sdk
    python check_ontology.py       # validates ontology.json against the SDK models
    python make_data.py            # regenerates data/*.csv and data/raw/*.csv (deterministic)
    python clean_crm.py            # asserts clean(raw) == data/*.csv

## Rebuild it in Foundry

You need your own Foundry enrollment. The repository does not include the Foundry repository templates; create them in Foundry.

1. Create a Python transforms repository in Foundry. Copy `foundry/transforms/crm.py` to `myproject/datasets/crm.py` and `crm_ontology/clean_crm.py` to `myproject/clean_crm.py`.
2. Set `P` in `crm.py` to your project folder. Set `FOUNDRY_USERS` to map a sales rep to your Foundry user id.
3. Upload the 7 files in `crm_ontology/data/raw/` as datasets in that folder. Build the 7 transforms.
4. Create the object types, link types and action types as described in `crm_ontology/README.md` and the guide.
5. Create a TypeScript v1 functions repository. Copy `foundry/functions/index.ts` to `functions-typescript/src/index.ts`. Publish it, then use the functions in the `assign-lead` and `convert-lead` actions.
